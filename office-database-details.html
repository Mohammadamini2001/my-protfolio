Office Database System - Database Features

This page lists only the data and database-related capabilities of the Office Database System, including entities, finance schema, integrity controls, reporting, and backup support.

Back to Projects

Core Data Entities

  • Normalized records for customers, visas, and office operations.
  • Structured authentication and user account data.
  • Finance data entities for income, expenses, loans, and journals.
  • Audit-ready data shape for key business actions.

Schema and Relationships

  • Dedicated finance schema definitions for consistent storage.
  • Relationship-friendly layout for linking customer and transaction data.
  • Predictable table and field naming to simplify maintenance.
  • Migration-friendly SQL structure for future expansion.

Transaction and Accounting Data

  • Income and expense entries stored with category-level detail.
  • Journal and ledger support for accounting visibility.
  • Loan records with tracking and detail views.
  • Personal expense tracking separated from office finance data.

Integrity and Control

  • Period lock model to protect finalized accounting windows.
  • Audit logging structure for user actions and data changes.
  • Role-aware access patterns for sensitive database areas.
  • Consistent read/write boundaries through route-level controls.

Reporting and Queryability

  • Report-oriented query outputs for printable financial reports.
  • Ledger and journal views driven by query-ready datasets.
  • Status and dashboard pages fed by aggregated data.
  • Filtering support for operational and accounting inspection.

Backup and Recovery Support

  • SQL backup strategy supported by PowerShell backup script.
  • Timestamped backup naming for recovery traceability.
  • Dedicated backup folder for operational safety.
  • Deployment-ready structure with environment-aware configuration.
